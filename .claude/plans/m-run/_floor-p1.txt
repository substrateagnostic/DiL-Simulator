
=== THE 21-CELL CASUAL FLOOR (800 runs/cell, CASUAL policy) ===
CASUAL policy: basic attacks, the free starter heal, Assert Dominance when the
bar fills on its own. Never a tagged hit, never a Brace, so it denies 0.0 % of
enemy turns on every solo rung and every denial-gated component is unreachable.

The three columns are the resistance the player has REQUISITIONED (the shipped
Performance Improvement Plan at 0 / 10 / 25 recorded defeats). A mode with an
assist takes the MAX of the two, so:
  • column PIP 0 %  measures the ASSIST — Casual lifting an unaided player.
  • columns 20/30 % measure the PHASE SURGERY ALONE, because the assist is
    already saturated there and both arms run the same resistance. THAT is the
    bill, and it is the pair of columns the gate is read on.
Judge against the NULL ARM (the identity bundle measured a second time), never
against a round number.
